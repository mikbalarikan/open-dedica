# AliExpress Shopping List — Open Dedica (230 V build)

Companion to [SOURCING_GUIDE.md](SOURCING_GUIDE.md) and [BOM.md](BOM.md). This is the BOM trimmed to what you can realistically order on **AliExpress**, grouped into carts so you can tick items off as you order.

> **Caution:** AliExpress listings appear and disappear constantly. Search links below open a live search, not a specific product — check the photo, the part code and the voltage before paying. We have no relation to any seller.
>
> **⚡ Voltage:** almost everything on AliExpress is **230 V**. If you are on 120 V mains, do **not** buy the pump, thermoblock, PCB or TCO here — see the US sources in the sourcing guide.

**How to use this list**

1. Pick a strategy: **Donor route** (recommended, buy only Carts 2 + 5 + one of 4A/4B) or **All-new route** (Carts 1–5).
2. Pick an electronics path: **4A — OEM PCB** or **4B — ESP32 open controller**. Not both.
3. Search by the OEM code first, then by the description. Sellers often list Dedica parts under **EC680** — the EC680 / EC685 / EC885 wet side is interchangeable for this project.
4. Try to buy each cart from **one store** (one shipment, one customs event). Most De'Longhi-spares stores carry the pump, thermoblock, PCB and gaskets together.
5. Check your country's import/customs limits before one big order — it may be cheaper to split.

## Not on AliExpress — buy elsewhere

| Item | Where | Why |
|---|---|---|
| Donor Dedica EC680 / EC685 / EC885 (broken is fine) | eBay, local classifieds (`Dedica EC685 defekt`, `arızalı Dedica`) | cheapest source of every OEM part — see Strategy A |
| Heater SSR ≥25 A + heatsink, pump SSR/relay (Path 2) | RS / TME / Mouser / local distributor | mains safety, counterfeit risk |
| Small OEM-only parts not found on AliExpress (spacers 61, connections 67/70, 3-way connector 75, tubes 31/33/71–73) | FixPart, 4delonghi, espressocoffeeshop | exact OEM geometry; often cheaper to take from the donor |
| ABS / ASA filament (heat side) + PETG (cold side) | local filament shop | shipping weight, freshness |
| High-temp epoxy (steam port blank) | hardware store | |

## Quick carts

**Donor route (recommended), ~€60–90 on AliExpress:** donor machine elsewhere + Cart 2 + Cart 5 (+ Cart 4B if going ESP32; the donor already provides Path 1 electronics).

**All-new route, ~€200–300 on AliExpress:** Carts 1 + 2 + 3 + 5 + either 4A or 4B, plus the "buy elsewhere" OEM small parts.
